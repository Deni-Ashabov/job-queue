# Job Queue

Очередь задач на Go с HTTP API и фоновым воркером.

## Архитектура

- **API сервер** (`cmd/api`) — управление задачами через REST API
- **Воркер** (`cmd/worker`) — фоновая обработка задач из очереди
- **PostgreSQL** — хранилище задач
- **chi** — HTTP роутер

## Возможности

- Создание и удаление задач через API
- Получение статуса задачи по ID
- Фоновая обработка задач воркером
- Базовая аутентификация для защищённых эндпоинтов
- Логирование с поддержкой разных окружений
- Миграции базы данных

## Запуск

### API сервер

```bash
go run cmd/api/main.go
```

### Воркер

```bash
go run cmd/worker/main.go
```

## Конфигурация

Конфигурация через YAML файл и переменные окружения (`.env`):

- `DB_URL` — строка подключения к PostgreSQL
- `HTTP_SERVER_USER` — пользователь для базовой аутентификации

Пример конфига: `config/prod.yaml`

## Миграции

```bash
# Применить все миграции
make migrate-up

# Откатить последнюю миграцию
make migrate-down

# Создать новую миграку
make migrate-create name=add_new_field
```

## API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/job` | Создать задачу |
| GET | `/job/{jobID}` | Получить задачу |
| DELETE | `/job/{jobID}` | Удалить задачу |

Все эндпоинты кроме `GET` требуют базовую аутентификацию.

## Технологии

- Go 1.26
- chi — HTTP роутер
- pgx — драйвер PostgreSQL
- cleanenv — загрузка конфигурации
- slog — логирование
